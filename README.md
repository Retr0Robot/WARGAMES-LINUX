Personal documentation on what I learn playing wargames and using linux terminal

## OverTheWire.org 

 OverTheWire Wargames is a free online platform designed to teach Linux, CyberSecurity, and ethical hacking skills.

 Instead of reading tutorials OverTheWire.org lets you connect to remote servers and solve progressively harder puzzles that require you to use Linux commands, scripting, networking, cryptogrophy, and security concepts.
